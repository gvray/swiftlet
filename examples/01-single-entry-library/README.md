# 01 Single Entry Library

Demonstrates the most common Swiftlet use case: a single-entry JavaScript library outputting ESM, CJS, and UMD formats.

## Run

```bash
pnpm build
```

## Expected output

```
dist/
  swiftlet-example-01-single-entry-library.esm.js
  swiftlet-example-01-single-entry-library.cjs.js
  swiftlet-example-01-single-entry-library.min.js
```
