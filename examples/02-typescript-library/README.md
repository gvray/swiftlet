# 02 TypeScript Library

Demonstrates a TypeScript library build with automatic `.d.ts` generation.

## Run

```bash
pnpm build
```

## Expected output

```
dist/
  swiftlet-example-02-typescript-library.esm.js
  swiftlet-example-02-typescript-library.cjs.js
  swiftlet-example-02-typescript-library.min.js
  swiftlet-example-02-typescript-library.d.ts
```
